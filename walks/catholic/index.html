海風無界來遠客・信仰相逢山水間

踏查天主教
臺灣北部之路

國立臺灣博物館「天主教來臺400年」系列走讀的一場。跟著王善卿博士，從民生西路的主教座堂出發，經過道明會的修女會院、靜修女中，沿著中山北路一路走到聖多福天主堂。兩個小時裡聽到修會怎麼來、教堂為什麼長這樣、聖像怎麼認，也看到今天臺北的天主教堂裡，週日坐滿的是誰。

日期2026/11/22（日）10:00–12:00講師王善卿博士・天主教臺北總教區天主教初傳臺灣400年委員會委員主辦國立臺灣博物館集合聖母無原罪主教座堂（民生西路天主堂，民生西路 245 號）路線主教座堂 → 道明修女會 → 靜修女中 → 馬偕醫院 → 雙連教會 → 中山北路 → 聖多福天主堂
1626→ 2026・四百年

1626 年，道明會傳教士隨西班牙船隊抵達北臺灣，開啟天主教在臺灣的早期傳播。四百年來，天主教和臺灣的地方社會、文化交織出許多痕跡。這場走讀把展覽裡的「教堂」與「文化地景」帶到博物館外：從建築、街區、移動人口、社會服務和地方記憶，看宗教怎麼和臺北一起長成今天的樣子。

當天剛好是天主教的「基督君王節」，各堂從早到晚彌撒一場接一場，主教座堂和長安堂都沒能進去，聖多福也只能在空檔溜進去看一眼。以下照著走的順序整理，每站附當天拍的照片，點圖可放大、用方向鍵切換。

想自己去走走
・主教座堂、聖多福天主堂、靜修女中都在步行可到的距離：民生西路 → 中山北路一路往北，邊走邊看馬偕醫院的拱廊壁畫和雙連教會。
・想進教堂裡看，建議挑平日去；週日（特別是大節日）彌撒一場接一場，安靜站在後面看就好，不要在禮儀中走動。
・聖多福的院子裡就有整排聖像，平日也看得到；認聖像的訣竅：先看手上拿什麼、腳邊有什麼、穿什麼鞋。
・沒去成的長安堂、板橋的中華殉道聖人堂、士林的基督君王堂，都可以排進下一次。
