走進西門紅樓，開啟一場跨越百年的歷史文化之旅

西門紅樓
定時導覽

紅磚配灰白飾帶的辰野式建築，是萬華、也是西門町的地標。跟著紅樓的導覽志工，從八角樓裡的模型出發，繞到北廣場看立面、十字樓的太子樓、藏在角落的小八角、南廣場的第一賣店，最後在門柱和火燒牆前收尾——看一座 1908 年的公營市場，怎麼一路變成劇場、戲院，再變成今天的文創基地。

日期2026/1/30（五）14:00 起導覽志工劉旻華報到西門紅樓服務台費用免費路線八角樓 → 北廣場 → 十字樓 → 小八角 → 南廣場 → 門柱 → 火燒牆
  1. 1908日治時期的公營市場「新起街市場」，後改稱西門市場
  2. 1945 後二樓改成劇場，演京劇、說書給戰後來臺的觀眾
  3. 1958–1996改成戲院，放了三十多年電影
  4. 今天臺北西區的文創與藝文展演基地

活動簡介寫的是 40 分鐘，當天老師講得很投入，實際走了快一個小時。以下照著走的順序整理，每站附當天拍的照片，點圖可放大、用方向鍵切換。

想自己去走走
・紅樓的定時導覽免費，到一樓服務台報到即可；週五下午北廣場已經在搭假日市集的棚子，週末更熱鬧。
・繞八角樓外圈一圈不用十分鐘：看紅磚與白色橫帶、拱心石、老虎窗、盲窗，再到後方找那座小八角。
・門柱在成都路一側入口，菊花紋的鐵件近看最清楚；火燒牆在十字樓裡，可以摸摸看。
・附近的成都路天后宮，供奉著一尊弘法大師像，走幾步就到。
