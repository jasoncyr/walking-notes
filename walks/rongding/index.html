2025 打開台北 Insider 導覽志工培訓・專家帶路

老城建築
榮町衡陽路

這一場由臺北市古蹟及歷史建築保存基金會在「衡陽35」接待，先看一棟 1912 年落成、寬只有 4.8 公尺的老街屋怎麼被重新使用，再由研究臺北城市史與傳統建築的鄭聖吉老師帶著走上衡陽路：從「城內、城中、榮町」三個詞到底差在哪，到對面四棟老屋的四種修法、菊元百貨、電話局、書局和唱片行的故事，一路講的都是「要講就講準」。

日期2025/09/14（日）10:00–11:30分享人鄭聖吉老師（文化史蹟導覽解說員）集合衡陽35（台北市中正區衡陽街 35 號）活動2025 打開台北 Insider 導覽志工培訓・專家帶路路線衡陽35 一樓 → 二樓 → 三樓 → 室內簡報 → 衡陽路騎樓 → 對面四棟老屋 → 菊元百貨 → 榮町地圖 → 三五與隔壁書局 → 回衡陽35

這一場，要來了才知道的事

  1. 平常不太看得到的內部衡陽35 是基金會 2025 年初才進駐的據點，牆上刻意留著調查時敲開的破洞，二樓是科技藝術團隊的工作室，三樓有 50 種香氛原料能一瓶一瓶聞。
  2. 只有現場才聞得到的城市三樓的調香團隊替衡陽35 調了一款專屬香氣，也做過郵局、城隍廟和二二八公園的味道。
  3. 老師的手繪稿為了弄清楚每一戶的前世今生，老師把整條街一戶一戶畫下來、對門牌、對地形圖。這份手稿，是講義之外才看得到的東西。
  4. 江山樓分店，答案是最醜的那間網路上大家都猜外觀漂亮的那一戶，老師用放大的老照片比對招牌，最後確認是現在整面刷白、最不起眼的那一間。
  5. 一位十五歲店員的後來三五隔壁的書局，曾經有位小學畢業的年輕店員，後來創辦了一家家電集團。故事怎麼來的，現場聽比較有味道。
  6. 一堂導覽員的基本功站哪裡、怎麼靠邊、怎麼不擋店家的路，老師現場一邊走一邊示範：「從出門那一刻就是在上課。」

以下照著當天的順序整理，每站附當天拍的照片，點圖可放大、用方向鍵切換。標了 現場限定 的，是平常自己來逛不容易看到或聽到的內容；時間為約略時段。

想自己去走走
・先站在衡陽35 門口，再往對面看：四棟並排的老屋，有一棟幾乎沒修（全祥茶莊）、一棟只換了表面、一棟用小磚保留線條、一棟文創再利用，剛好是四種修法的現成教材。
・走到菊元百貨（現在的國泰金融大樓）轉角，對照那張 1920 年的榮町地圖，想想為什麼界線會沿著防火巷畫。
・看每一戶的立面線條：一樓、二樓、三樓的橫線高度是統一的，造型卻各自不同。
・找找兩戶之間的厚牆；看哪些老屋把補強的鋼構露出來，哪些把它藏起來。
・衡陽35 一樓平常有展覽與講座，行程可以先看基金會的公告；想聞調香原料或看老屋破洞，記得上三樓。
