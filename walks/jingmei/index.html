2025/09/20

家—城 II《另一種現場：建築講座×走讀》第三場

尋找修澤蘭
景美女中

修澤蘭是臺灣第一位女建築師。這一天從校門口的白色弧形拱開始，上午在校內圖書館聽講座，看一個建築模型是怎麼從舊圖面裡長出來；下午把耳機戴上，沿著椰林、池塘、藝能館與行政大樓走一圈，由校友、老師與學員輪流說出自己和這座校園的故事。從「家園」到「校園」，再到蓋出這一切的「公共建設」，一天走完。

日期2025/09/20（六）09:50 集合・10:00–12:00 講座・13:00–15:00 走讀講座「景美女中校園巡禮」廖子喬走讀「尋找修澤蘭－景美女中」何黛雯地點景美女中（台北市文山區木新路三段 312 號）路線校門 → 圖書館 → 午餐・一人三步 → 宿舍外 → 行政道 → 校門 → 池塘・花架 → 藝能館 → 行政大樓 → 新建校舍・體育館 → 圖書館

這一場，要來了才知道的事

  1. 一棵用學號認領的椰子樹走在行政道上，一位 1990 年入學的校友指著一棵樹說：那是她的。入學時每人依學號後三碼認養一棵，樹上釘著小鐵牌，現在牌子沒了，她還記得位置。
  2. 要抬頭、要輪流站進中央的天花板圖書館的屋頂由八條梁放射匯聚，像一顆八角星。講者請大家輪流走進正中央往上看，這個角度平常沒有人會站。
  3. 水順著柱子流下去圖書館的屋面是淺碗狀，雨水從排水孔灌進柱子、由柱底排出。這種細節在圖面和現場對照時才看得見。
  4. 連當年怎麼灌模，都還是謎講者做模型時發現：圖面把家具、開關、燈具都畫了，卻沒有施工。柱子下窄上寬、梁也是圓的，到底怎麼蓋出來，現場一起討論，最後連模型的柱子都是 3D 列印一根一根插上去。
  5. 一尊每年變裝的銅像行政大樓中庭曾立著一尊銅像，美術老師每年都讓它跟著校慶美展變裝，聖誕節是聖誕老人、校慶是穿制服的景美學生。後來銅像移走，還辦了一場回顧展。這個故事是在現場由老師親口說的。
  6. 只在中午出現的光影樓梯一位學員中午特地來拍樓梯上的光影，走讀時已經看不到了。她說，那是「期間限定」。

以下照著當天的順序整理，每站附當天拍的照片，點圖可放大、用方向鍵切換。標了 現場限定 的，是平常自己來逛不容易看到或聽到的內容。

想自己去走走
・先從校門口看三個「圓」：拱門的弧、行政大樓像傘一樣張開的白柱、圖書館像花瓣的屋頂。它們是同一套語彙。
・進圖書館先抬頭看八角星天花板，再看柱子：不是直的，下窄上寬，然後向屋面綻開。
・沿著行政道找一棵樹：用你的學號後三碼想像它。大王椰子落葉很重，樹下請注意頭頂。
・到藝能館看中庭，會淋雨、種著一棵雞蛋花；再抬頭看二樓樓板，沒有看得到的梁，薄得像飄在空中。
・校園不是公園，走讀當天是主辦單位事先與學校聯繫；想自己去之前，先向學校確認可以入校的時間。
・手邊如果有一張紙，可以學當天的「一人三步」：一個人走，拍一張照，寫一句話。
關於這場活動
這是 WAT 2025 春夏《家—城 II：另一種現場》系列的第三場，配合《另一種現場：修澤蘭》展覽與《島嶼煉石記－修澤蘭‧建築山河》新書。「家—城」想問的是：一座城市如何長成我們成長的家，又將走向哪裡？這一場從「家園」走進「校園」，再談到支撐這一切的「公共建設」。
