2025/05/04

香火傳承中的常民智慧

孚佑百年
大稻埕仙公廟走讀

真聖堂迎奉孚佑帝君呂恩主滿一百年，廟方辦了一場文化走讀。跟著在大稻埕長大的藍世昌老師，從延平北路巷子裡的仙公廟出發，繞過延平北路、永樂市場、迪化街和貴德街，兩個多小時後又回到廟口。一路上聽到的，是讀書人、茶商、漢醫、藝旦和酒家怎麼把這片街區連在一起。

日期2025/05/04（日）14:00–16:10導覽藍世昌老師・在地子弟、文史解說老師主辦大稻埕仙公廟真聖堂管理委員會承辦中國科技大學、三重埔文史協會集合真聖堂（臺北市大同區延平北路二段 61 巷 16 號）
1925→ 2025・孚佑百年

真聖堂靜靜待在延平北路二段的老街廓裡，從讀書人學漢文的書房、扶鸞的鸞堂，一路成為今天的仙公廟，也看著大稻埕從河港商埠變成文化聚落。這場走讀以「香火傳承中的常民智慧」為題，想從三個角度看一座廟：

建築裡的信仰密碼空間佈局、裝飾與楹聯，藏著什麼樣的宇宙觀。
儀式中的生活哲學節慶祭儀背後，先民對自然與生命禮俗的智慧。
廟埕外的文化網絡廟宇怎麼和茶行、布市、南北貨商號連成地方的人際與經濟網。

實際走的路線是：真聖堂 → 法主公廟・天馬茶房 → 延平北路 → 渭水驛站 → 永樂市場 → 迪化街 → 霞海城隍廟 → 廟前街 → 李臨秋故居 → 莊協發 → 李春生紀念教會 → 陳天來故居 → 李家舊宅・鹽館 → 迪化街北段 → 林復振 → 波麗路 → 真聖堂。原本排在最後的大稻埕碼頭這次沒有走到。以下照著走的順序整理，每站附當天拍的照片，點圖可放大、用方向鍵切換。

想自己去走走
・真聖堂在延平北路二段 61 巷內，一樓是道教、二樓是佛殿；記得看門口嵌著「真」「聖」「孚佑」的對聯，和中日文並列的籤詩。晚上開燈後的夜景很漂亮。
・整條路線都在步行距離內，約兩小時。迪化街週末人潮很多，「走路最大」時段車輛管制，想拍街屋立面建議平日早上去。
・貴德街的陳天來故居還在整修，完工後可以再回來看樓梯的玻璃和二樓陽臺。
・延伸參觀：寧夏路的新文化運動紀念館（蔣渭水）、臺博館大廳的水果牛眼窗、農曆五月十三的霞海城隍遶境。
