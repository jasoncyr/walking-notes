中央研究院建築與院區導覽・12/13 場

人文大道與早期經典建築

陰天偶爾飄雨的週六下午，跟著蔣雅君老師從院區大門一路走到胡適墓園。王秋華的現代主義、王大閎的「民族形式」、漢寶德在民族所屋頂上蓋的一座閩南小聚落，再到基泰工程司留下的幾棟老房子——一條人文大道，大概就是臺灣 1950 到 1990 年代的建築史。

日期2025/12/13（六）14:00–16:30主辦中央研究院集合人文社會科學館 2F 第一展區（南側梯廳）入口路線院區大門 → 四分溪 → 歐美所圖書館 → 歷史文物陳列館 → 民族所 → 傅斯年圖書館 → 考古館 → 胡適紀念館・故居 → 胡適墓園
1954–1986→ 一條路上的四十年

中研院在南京時期的房子走的是中國古典式樣；1954 年在南港四分溪畔復院後，前期由基泰工程司蓋了一批簡潔、實用的現代主義房子，1970 到 80 年代才有王秋華、王大閎、漢寶德各自留下代表作。展覽在人文社會科學館二樓南北棟梯廳（週一至週六 9:30–16:30），導覽則把展板上的房子，帶到院區裡一棟一棟去看。

13:45 開放報到，先在展場看了一陣子才出發。前四站（大門、四分溪、歐美所圖書館、歷史文物陳列館）沒有留下照片，從民族所開始才邊走邊拍。以下照著走的順序整理，點圖可放大、用方向鍵切換。

想自己去走走
・院區平日可以進去散步：人文大道一條路走下來，就能看到王秋華、王大閎、漢寶德三位建築師的作品，再往北拐進適之路就是胡適紀念館，過馬路上坡是胡適墓園。
・民族所屋頂和內部平常不對外開放，這天是所方特別幫忙才進得去；一樓的民族學研究所博物館、歷史文物陳列館、胡適紀念館都有開放時間，出發前先查好。胡適故居室內不能拍照。
・交通：院內有 YouBike 站；機車只能停院外，汽車可停人文館地下室或院內停車格臨停。
・導覽搭配的展覽（人文館二樓南北棟梯廳，週一至週六 9:30–16:30）建議提早 30–40 分鐘先看，再出門走，會更有感覺。
