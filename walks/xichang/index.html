西昌街走讀筆記
從艋舺的中心點說起

西昌街是清代艋舺最核心的一條街，由廈新街、土地前街、土地後街、半路店街等幾段接成。跟著吳讚軒老師從 177 號走到長沙街，沿路用舊照片比對：被拓寬切掉的店屋、被火燒掉的市場、擋路而被遷走的土地公廟，以及百年前「不可敵國」的艋舺家族。

日期 2024/04/30（二）14:30–16:30・下午場活動 臺北市萬華社區大學・公民素養週「友善地球：從西昌街說起的艋舺故事」導覽 吳讚軒老師（臺北市艋舺源文化協會會長、艋舺文化工作執行長）集合 西昌街 177 號路線 西昌街 177 號 → 桂林路口 → 康定路 → 王家老屋二進門 → 直興市場 → 廈新街 → 艋舺中心點 → 媽祖宮口 → 艋舺福德宮 → 土地後街 → 長沙街天氣 陰，中段與尾段兩度下雨，多半在騎樓下聽講

為什麼要走這一趟

很多人對西昌街的印象，是從龍山寺捷運站走過來那一段：熱鬧、擁擠，甚至有點髒亂。但清代的西昌街是艋舺最核心的區域，由半路店街、土地後街、土地前街、廈新街等幾段街道組成，承載了幾百年的歷史。老師說，一百年前艋舺最有錢的人家，就是沿著這條街一路往北排開。

這場由萬華社區大學公民素養週辦的走讀，主題是環境永續，所以老師開場先提醒大家：來艋舺玩，記得自備餐具、少用塑膠袋、讓街區維持乾淨。接著他帶著一本厚厚的資料夾，沿路拿出老照片與老地圖，讓大家看見這條街因為商業考量或道路拓寬而失去的樣子。

走讀的方式：這一場幾乎每一站都有「今昔對照」。老師不是只用嘴講，而是站在現場，把舊照片舉到眼前，請大家比一比：一樣的位置，一百年前、四十年前是什麼樣子。照片、地圖和家族資料都在他手上，要在場才看得到。

文中的年代、數字與家族故事，都是老師現場口述的說法；有些部分與一般文獻說法略有出入，想深究的話，建議再查閱《臺北文獻》與相關史料。

這一場才看得到、聽得到的

街可以自己走，但下面這些，多半要跟著老師、在現場、在那一刻才會碰到。點進去看那一站。

下次自己來，可以這樣看

・直興市場週一有開、週日休，和多數市場相反；周邊餐廳週日也大多不開，想吃甜不辣和日料，要避開週日；日料店下午四點後才營業。

・從 177 號走到康定路，就是一棟「五進」老屋的長度；想有感，不妨自己用腳步量一次，再回頭看雙黃線的位置。

・艋舺福德宮在長沙公園裡，廟小，神龕與木雕神像是從老廟帶過來的；可以對照柱上的對聯與匾額，找「正位中央居艋舺」那一句。

・這一帶很多線索在高處與縫隙：清代山牆的石材、夾在新大樓之間的紅磚老屋、騎樓上的舊招牌。抬頭多看一眼，走慢一點。
