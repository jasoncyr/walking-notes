你知道兩廳院的新鮮空氣從哪裡來嗎？

好事度量
機電導覽專場

《好事度量》永續特展的一場特別導覽。前半段跟著兩廳院機電組的空調專員，走進平常進不去的後台機房，從屋頂的新鮮空氣入口一路追到冰水主機和停車場；後半段由山峸製作設計的袁浩程帶大家看展，聊共融服務，也聊這個展怎麼盡量不製造垃圾。

日期2026/1/6（二）11:00–12:00地點國家兩廳院機電導覽彭志傑・兩廳院機電專員（空調維護）展覽短講袁浩程・山峸製作設計執行總監路線新鮮空氣入口 → 空調機房 → 空調箱 → 冰水主機房 → 停車場 → 後台 → 好事度量展區

彭志傑國家兩廳院機電專員・空調維護

虎尾科大自動化工程系畢業，冷凍空調乙級技術士。負責空調設備的自動控制與節能減碳，目標是讓兩廳院的空調穩定運作、零故障。

袁浩程山峸製作設計執行總監

北藝大劇場設計學系研究所畢業，舞台設計師、創業家與永續製作推廣者。2018 年創辦山峸製作設計，2020 年創辦「北投小戲節」，2022 年完成國內劇場製作界第一篇永續製作研究論文，2025 年成立非營利組織「峸劇場」。

以下照著走的順序整理，左邊是大約的時間。每站附當天拍的照片，點圖可放大、用方向鍵切換。

想自己去看看
・機房平時不開放，但《好事度量》展區裡的觸覺模型、情境字幕和口述影像小房間都可以自己體驗：觸覺模型建議閉上眼睛摸一次。
・展區的投票 QR code 可以現場掃，結果會即時投在牆上。
・下次進兩廳院看戲，可以留意大廳和觀眾席的溫度：平常大約維持在 23 度上下，冬天偏乾、容易有靜電，是因為空調箱沒有加濕。
・各項共融服務（口述影像場、輕鬆自在場、多元友善席、助聽系統）都可以在兩廳院官網查到場次與申請方式。
