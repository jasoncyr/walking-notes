# 遠任的走讀筆記

依錄音與現場照片整理的走讀筆記網站（GitHub Pages）。

- `index.html`：首頁，依春夏秋冬分段的封面卡片
- `walks/<代號>/index.html`：每一場的筆記頁，照片在 `walks/<代號>/img/`
- `thumbs/`：首頁封面縮圖

目前已搬到這裡的場次：anken（安坑輕軌春日行，2024/04/24）、zoo（動物園的指標系統，2024/08/31）、catholic（踏查天主教臺灣北部之路，2026/11/22）、rongding（老城建築：榮町衡陽路，2025/09/14）、jingmei（尋找修澤蘭：景美女中，2025/09/20）、liuguan（店屋古厝：六館街尾洋式店屋，2025/09/13）。
其他場次暫時連回 claude.ai 上的原網頁。

## 頁面規格（每一場都要一致）
- 左側「全部走讀」清單：標題區（‹ 遠任的走讀筆記、全部走讀・N 場）包在 `<div class="yr-head">` 裡，固定在清單最上方；季節標籤 `li.yr-se` 也會固定在標題區下方。對應的 `<style>`（`.yr-head{position:sticky…}`）與設定 `--yr-hh` 的小段 `<script>` 要一起放進每一頁。
- 新增場次時，記得同時更新所有既有頁面的清單與上一場／下一場連結。
